# 2026-09-26 — stage1-02 학습 결과 분석

## 대상

`results/stage1-02` — 3.5M/5M 스텝에서 중단, 100분, 570 step/s, **단일 환경**,
`time_scale: 20`. 내보낸 ONNX의 연속 출력이 43개라(stage1-01은 41) 어깨
축회전을 연 **뒤**의 런이다. stage1-01은 GroundContact 버그 런이라 비교 대상이
아니다.

보상 −2.35(20k) → 0.79(1.22M) → 1.24(2.18M) → 1.31(3.5M), 에피소드 길이
188 → 51 결정. **2.2M에서 평탄해진다** — 구간 평균 1.215 → 1.197 → 1.233으로
1.3M 스텝에 +0.02다. value loss가 0.002까지 떨어졌으니 critic은 수렴했고 남은
건 정책이다.

## 실측 평가 — 16영역 추론, 362 에피소드

학습은 1영역, 평가는 회전된 16영역에서 했다. limb별 75~81%로 고르니 **영역
회전은 전이에 영향이 없다**(관측을 벽 프레임으로 잡은 설계의 값). 성공률
**74.9 %**, 추락 **0 %**, 나머지 25%는 전부 타임아웃. 성공은 65 agent
step(1.3 s), 실패는 MaxStep 1000(20 s)을 꽉 쓰고 시작 거리 0.564 m에서
0.538 m로 **20초에 2.6 cm** 움직인다.

## 핵심: 실패 = "놓지 않았다"

| 시작 거리 | 성공 | 지정 limb을 한 번이라도 release |
|---|---|---|
| < 0.40 m | 51 % (21/41) | 49 % |
| 0.40–0.55 | 71 % (104/147) | 71 % |
| 0.55–0.70 | 79 % (82/104) | 79 % |
| 0.70–0.85 | 89 % (49/55) | 89 % |
| > 0.85 | 100 % (15/15) | 100 % |

**모든 구간에서 release율 = 성공률, 실패 91건 중 release한 건 0건.** 놓기만
하면 100% 닿는다. 모터 제어는 풀렸고 남은 실패는 전부 discrete branch의
release 하나다.

**가까울수록 안 놓는다.** progress가 `2 × (시작거리 − 현재거리)`라 시작
거리에 비례하는데 `minStep`이 0.30이고 `graspRadius`도 0.30이다. 가장 가까운
합법 타깃은 놓자마자 제자리에서 잡히는 거리라 progress ≈ 0 — **shaping이 가장
필요한 구간에서 shaping이 사라진다.** 게다가 놓는 순간 몸이 처져 거리가 잠깐
늘어 음의 shaping을 먼저 맞는다. 가까운 타깃은 "놓아 보는" 탐색이 초반에
손해라 안 놓는 쪽으로 굳는다.

## 부족한 점

1. **성공률이 로그에 없었다.** 3.5M을 돌리고 얻은 건 `Cumulative Reward`
   1.23 하나인데 그것만으론 75%인지 50%인지 모른다. 별도 평가 하네스를 붙여서야
   알았다(`ClearTime/<limb>`은 성공만 기록해 실패율을 못 본다). 분석 도중
   `Success/<limb>`가 커밋됐으니 다음 런부터는 그래프로 보인다.
2. **추락 패널티가 죽은 코드다(0/365).** 세 limb이 월드에 고정돼 hips가 1 m
   떨어질 수 없다. `docs/05` 보상 표는 추락이 실제 종료 경로인 것처럼 읽힌다.
3. **타임아웃이 예산을 먹는다.** 에피소드 평균 300 step(성공 65 / 실패 1000).
   25%의 실패가 **전체 스텝의 84%**를 쓴다.
4. **엔트로피가 안 내려간다.** 1.4265 → 1.4225. σ = exp(H − ½ln2πe)로 풀면
   1.008 → 1.004, 즉 3.5M 뒤에도 **초기값 σ≈1.0 그대로**다. action 범위가
   [−1,1]인데 노이즈가 ±1.0이다. 2.2M 평탄화와 맞물린다.
5. **단일 환경.** `env_step`이 벽시계의 92.6%다. 병목은 Unity 물리인데 영역이
   하나였다.

## 개선 (우선순위)

1. **release율도 찍는다.** `Success/<limb>`는 들어갔다. 이번 분석의 결론이
   "실패 = 안 놓음"이므로 `Released/<limb>`(에피소드 중 지정 limb이 한 번이라도
   풀렸는가)를 같이 찍으면 다음 런에서 이 실패 모드를 바로 감시할 수 있다.
2. **가까운 타깃의 shaping 구멍을 막는다.** (a) `minStep`을 `graspRadius`보다
   크게(0.30 → 0.45), 또는 (b) progress를 시작 거리로 정규화해 거리와 무관하게
   같은 총량을 주기. (a)가 한 줄, (b)가 관측된 기울기를 직접 없앤다.
3. **`MaxStep` 1000 → 300.** 성공이 65 step이니 넉넉하다. 에피소드 평균이
   300 → 124로 줄어 **같은 예산에 2.4배** 돈다.
4. **`beta` 0.005 → 1e-3을 시험.** 엔트로피 정체가 평탄화의 원인인지 보는
   가장 싼 실험이다.
5. **16영역으로 돌린다.** 이미 씬에 있다. 3~5는 곱해지는 효과다.

## 추가 — stage1-03: 발 100 %, 손 0 %

위 개선안을 넣고 돌린 `stage1-03`(2.4M)에서 `Success/<limb>`가 갈라졌다.

| | LeftFoot | RightFoot | LeftHand | RightHand |
|---|---|---|---|---|
| 2.38M 시점 | **1.00** | **1.00** | **0.00** | **0.00** |

`ClearTime/RightHand`는 태그조차 안 생겼다 — 한 번도 성공한 적이 없다는 뜻이다.
보상은 0.97에서 멈췄고 에피소드 길이 34결정은 "발은 8결정에 끝내고 손은 60결정
타임아웃"의 평균이다. 즉 **절반이 순수 타임아웃**이다.

왜 손만인가. progress가 `2 × (이전 거리 − 현재 거리)`로 **대칭**이라 벌어진
거리를 매번 청구했다. 손을 놓으면 몸이 매달린 지지점을 하나 잃고 처지므로
**거리가 먼저 벌어진다.** 발은 몸 아래에 있어 놓아도 자세가 거의 안 흔들린다.
그래서 같은 보상 함수가 손에게만 "놓지 마라"로 작동했다.

## 고친 방법 두 가지

1. **progress를 래칫으로.** 최근접을 갱신할 때만 준다. 멀어지는 건 공짜다.
   합은 여전히 시작 거리로 묶이고 흔들어서 벌 수도 없다(1 cm는 한 번만 값을
   치른다).
2. **`releaseReward` +0.1**, 지정 limb이 처음 놓는 순간 한 번. 래칫은 시도의
   *벌점*만 없애므로 "놓았지만 한 번도 가까워지지 못한" 시도는 안 놓기와
   동점이 된다. 이 보너스가 시도를 확실히 위로 올린다. 지정 limb은 원래 홀드를
   다시 못 잡으므로(`CanGrasp`가 목표 홀드만 제안) 반복 수령이 불가능하다.

## 실측 (stage1-02 모델, 16영역)

-   **보상이 시간 패널티 바닥 아래로 내려간 경우 0/136.** 멀어지는 데 값을

| 지표 | 측정 |
|---|---|

보상은 자기 천장(+1.98)에 정확히 붙어 있었다 --- 정책은 배운 대로 완벽하게

grasp 조인트가 힘 제한 없는 위치 고정이라 물리가 이걸 처벌하지 않고, 낙차와

## 고친 것

-   **`facingPenalty` 삭제.** 측정상 발동 0.00%(등을 돌리는 일 자체가 없었다)
    였고, `initialize_from`으로 이어 학습할 때 안 쓰는 항을 남겨 둘 이유가
    없다.
-   **낙차 패널티** `−0.02 × (낙차 − 0.4)`, 문턱(`dropPenaltyThreshold` 0.4 m)을
    넘을 때만, 매 스텝. `maxDrop`(1.0 m, 종료 문턱)은 그대로 뒀다 --- 이건
    그 안쪽에 **처음 생기는 압력**이지, 문턱을 조인 게 아니다.
-   **그립 하중 패널티** `−0.01 × (GripLoad / Capacity − 1)`, 잡고 있는 limb마다
    초과분만. `Capacity`(손 1.0 BW·발 2.0 BW) 자체가 "정상 등반에서 이만큼은
    걸린다"는 기준이라 그 안쪽은 공짜다.

둘 다 `stage1-04`의 최종 모델(재학습 없이)로 배선을 검증했다: 같은 정책,
같은 100% 성공인데 평균 보상이 **+1.98 → +0.295**로 떨어진다. 낙차는 여전히
평균 0.55 m로 문턱을 넘고, 그립 과적재 샘플이 전체 잡고-있는-순간의 **59.7%**
(초과분 평균 0.99배)다 --- 두 항 다 의도한 대상에 정확히 걸린다.
